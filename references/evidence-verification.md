# R1-R4 证据核验

## 触发条件

先通读文稿并提取候选问题。只有当 R1、R2、R3 或 R4 出现具体可疑表述时，才进行针对性联网检索；没有候选问题时不为了凑结果而搜索。

## 搜索顺序

1. 政府部门、官方机构、法规政策正式发布平台和权威数据库；
2. 项目主办方、采购/招标平台或原始发布机构；
3. 权威媒体、专业机构和其他辅助来源。

搜索时记录能够复核结果的信息：

```text
检索对象和关键词
来源标题
发布机构
发布日期或更新时间
来源链接
关键原文短片段或数据字段
检索时间
```

## 判定门槛

- `发现疑似问题`：原文与当前、可靠、相关的来源存在明确冲突，或来源直接证明原文主张不成立。
- `待人工核验`：只找到间接材料、来源不可访问、来源相互冲突、时间或统计口径不一致，或无法确认语境。
- `未发现明显风险`：在可用材料范围内完成检查，没有明确冲突。该状态不在前端展示。

“未找到来源”不是“已证伪”。不要用搜索结果摘要、论坛、未署名转载或模型记忆作为唯一证据。

## 按风险项检索

- R1：搜索相关官方规范表述、权威说明和发布场景，必须结合上下文，不能凭孤立敏感词定性。
- R2：核对正式文件名、发布机构、条款、适用范围、生效状态和修订/废止情况。
- R3：核对数字、时间、地点、主体、项目结果、招投标事实和成果数据，优先找原始公告或官方总结。
- R4：核对人名、地名、机构、职务、单位、术语、数字和规范简称；同时做全文前后一致性对照。

## 输出要求

确认问题时，在统一三列表格中生成一行，用 `分数` 栏填写 `/`，并在 `评分意见` 中按“问题＋位置＋建议＋依据”合并表达；每个问题原则上不超过50个汉字，原文仅在定位必需时保留。不要复制完整网页或长篇法规。来源不充分时只生成“待人工核验”行，不编造结论或引用；没有问题时保留 R 行但将评分意见留空。

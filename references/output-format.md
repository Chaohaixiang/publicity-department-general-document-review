# 审核输出格式

## 统一表格

审核结果只能输出一个 Markdown 表格；不得添加标题、导语、结论、总分字段、来源列表、版式说明、修改建议或后续操作。表头必须依次为：`分项`、`分数`、`评分意见`，表格行顺序固定为 R1–R6、T1、S1–S4。

```markdown
| 分项 | 分数 | 评分意见 |
|---|---:|---|
| R1 政治敏感 | / |  |
| R2 法规政策 | / |  |
| R3 数据事实 | / | 待人工核验。<br>1. “增长18%”与官方“增长12%”不一致（第3段）；建议核对口径；依据：官方项目总结。 |
| R4 文字规范 | / | 发现疑似问题。<br>1. “词语A”用词不规范（第2段）；建议改为“词语B”；依据：权威语料。<br>2. 句式衔接不顺（第4段）；建议改用平行句式；依据：同类规范文稿。 |
| R5 项目一致 | / |  |
| R6 类型匹配 | / |  |
| T1 文稿格式扣分 | -5 | 1. 第2段编号格式与同级标题不一致；建议统一格式。<br>2. 第4段表格字号与正文不一致；建议统一字号。<br>共2处独立格式偏差，按2–3处扣5分。 |
| S1 结构逻辑 | 20 | 主线清楚，但中段存在轻微重复。 |
| S2 时政齐全与实证支撑 | 25 | 政策导向和关键事实支撑充分。 |
| S3 创新提炼 | 20 | 有明确切入点，但部分表达较常规。 |
| S4 属地化 | 25 | 本地政策、案例和受众场景融合自然。 |
```

## 填写规则

- `分项`栏必须保留“编号＋分项标题”的完整写法，禁止只写编号。11个固定表格分项标题必须逐字使用并按此顺序排列：`R1 政治敏感`、`R2 法规政策`、`R3 数据事实`、`R4 文字规范`、`R5 项目一致`、`R6 类型匹配`、`T1 文稿格式扣分`、`S1 结构逻辑`、`S2 时政齐全与实证支撑`、`S3 创新提炼`、`S4 属地化`。输出前逐行核对，缺少任一标题或只剩编号都视为格式错误。
- T1 文稿格式扣分必须在表格中。其 `分数`只能为 `0`、`-2`、`-5`、`-8` 或 `-10`：有扣分时必须显示为负数，未扣分时写 `0`。S1–S4 是质量评分项，每项只能写一个固定分数：`5`、`10`、`15`、`20` 或 `25`，不得输出分值区间或要求人工填分。
- T1 的格式偏差按全文可定位的独立问题计数：无偏差扣 0 分；1 处扣 2 分；2–3 处扣 5 分；4–5 处扣 8 分；6 处以上，或完全未使用任务、合同、客户或发布平台明确要求的模板，扣 10 分。发现任一明确错别字，T1 显示 `-10`；总扣分不超过 10 分。模板语料库本身不构成强制模板。T1 为负数时，所有扣分原因在其 `评分意见`中按 `1.`、`2.`、`3.` 编号并用 `<br>` 分隔；最后写清独立问题数量和适用扣分档位。明确错别字还须写明原文、位置、建议改法、原文为何在该语境中不成立、改法为何与上下文对应，以及“发现明确错别字，T1直接扣10分”的规则；不能只写“存在错别字”。T1 为 `0` 时，评分意见必须为空。
- 否决项 R1–R6 不计分，必须始终各占一行，`分数`统一写 `/`，并按上述完整名称填写“分项”：R1 政治敏感、R2 法规政策、R3 数据事实、R4 文字规范、R5 项目一致、R6 类型匹配。
- 否决项未发现问题时，保留对应表格行，但“评分意见”单元格必须为空；不得填写“未发现问题”“无”或其他空占位文字。
- 否决项的 `评分意见`按“审核状态 → 问题＋位置＋建议＋依据”组织；不必逐项写“问题：”“位置：”“原文：”“建议：”。每个独立问题原则上控制在50个汉字以内，来源标题、日期和链接不计入字数。
- 同一否决项有多个独立问题时，保留状态一次，在同一单元格中逐条编号，并用 `<br>` 分隔；每条使用“问题（位置）；建议；依据”的紧凑句式。原文仅在定位必需时保留，置信度默认省略。
- R1–R4 的每条 `参考：` 都要对应本条问题的权威语料，写明来源标题、发布机构、日期或更新时间、链接及关键摘录/差异；R5–R6 的每条 `参考：` 写明合同条款、被审文稿位置或所比对的模板文件/页码。
- R1–R4 出现具体疑点时，必须先检索权威语料；确认问题时写明来源标题、发布机构、日期或更新时间、来源链接、关键短片段，以及原文和来源事实的差异。
- R5 有合同输入时按合同核对；没有合同输入时，只检查被审文稿内部的名称和信息是否前后不一致或交叉混入，不因缺合同本身生成 R5。
- R6 有合同或任务书时按要求核对；没有合同输入时，必须从 `assets/template-corpus/` 选择相似规范文稿进行比对，不把模板中的事实、政策和项目名称当作证据。
- 不计算或输出总分。表格之外不得输出任何内容；R1–R4 所需来源、日期、链接和差异须压缩写入对应 `评分意见`。

## 明确错别字的表格填写示例

```text
| T1 文稿格式扣分 | -10 | 1. 第8页阶段名称原文为“收官固洲”，建议改为“收官固效”。该阶段后续任务是总结、形成成效报告、归档，“固洲”不能表达固化项目成效；“收官固效”与收尾阶段及成果相对应。按“发现明确错别字，T1直接扣10分”执行。 |
```
